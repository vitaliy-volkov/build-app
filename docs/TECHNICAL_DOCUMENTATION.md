# Техническая документация проекта "Строй-Контроль"

## Обзор проекта

**Строй-Контроль** - это комплексная система управления строительными проектами, финансами и сметной документацией с интеграцией искусственного интеллекта.

### Ключевые особенности
- 🎯 Управление строительными проектами от планирования до сдачи
- 💰 Финансовый модуль с отслеживанием доходов и расходов
- 📊 Система смет с версионированием и анализом
- 🤖 AI ассистент для анализа и автоматизации
- 👥 CRM для работы с клиентами и лидами
- 📋 Система документооборота и актов КС-2/КС-3
- 📱 Интуитивно понятный интерфейс с адаптивным дизайном

## Текущее состояние

### ✅ Готовые компоненты (Фронтенд)
- **Технологический стек**: React 19 + TypeScript + Vite + Tailwind CSS
- **Архитектура**: SPA с контекстным управлением состоянием
- **UI/UX**: Полностью готовый интерфейс со всеми модулями
- **AI интеграция**: Поддержка множественных LLM провайдеров
- **Компоненты**: Все основные UI компоненты реализованы
- **Мок-данные**: Полный набор тестовых данных для всех модулей

### ❌ Отсутствующие компоненты (Бэкенд)
- **API сервер**: Полностью отсутствует
- **База данных**: Не настроена
- **Аутентификация**: Не реализована
- **Файловое хранилище**: Отсутствует
- **Real-time обновления**: Не настроены

## Технические детали

### Фронтенд (Готов)
- **Framework**: React 19.2.0
- **Language**: TypeScript 5.8.2
- **Build Tool**: Vite 6.2.0
- **Styling**: Tailwind CSS
- **State Management**: React Context API
- **Routing**: React Router v7.9.6
- **Charts**: Recharts
- **Icons**: Lucide React
- **AI Integration**: @google/genai, поддержка множественных провайдеров

### Бэкенд (Требует разработки)
- **Language**: Go 1.21+
- **Framework**: Gin Web Framework
- **Database**: PostgreSQL 15+
- **Cache**: Redis 7+
- **ORM**: GORM или sqlx
- **Authentication**: JWT + Refresh Tokens
- **File Storage**: MinIO (S3-compatible)
- **Containerization**: Docker + Docker Compose
- **Monitoring**: Prometheus + Grafana (опционально)

## Модули системы

### 1. Управление проектами
- **Функции**: Создание, редактирование, мониторинг проектов
- **Статусы**: Планирование, В работе, Приостановлен, Завершен
- **Команды**: Назначение ролей и ответственных
- **Дашборды**: Сводка по всем проектам компании

### 2. Система смет
- **Функции**: Создание, редактирование, версионирование смет
- **Типы позиций**: Этапы, Группы, Позиции
- **Ресурсы**: Работы, Материалы, Механизмы, Доставка
- **AI интеграция**: Анализ, оптимизация, автогенерация
- **Форматы экспорта**: CSV, PDF

### 3. Финансовый модуль
- **Функции**: Учет доходов и расходов
- **Типы операций**: Поступления, Расходы, Переводы, Зарплата
- **Кассы**: Наличные и безналичные счета
- **Отчеты**: P&L, Cash Flow, дебиторская задолженность

### 4. CRM система
- **Лиды**: От новой заявки до контракта
- **Статусы**: Новая, В работе, Встреча, Расчет, Договор, Успех/Отказ
- **Источники**: Сайт, Рефералы, Холодные звонки
- **Конвертация**: Автоматическое создание проектов

### 5. AI Ассистент
- **Функции**: Чат-помощник, анализ смет, оценка рисков
- **Провайдеры**: Google Gemini, OpenAI, Anthropic, Groq
- **Возможности**: 
  - Анализ проектного здоровья
  - Оптимизация расписаний (Gantt)
  - Генерация дизайн-изображений
  - Распознавание речи для создания смет

### 6. Документооборот
- **Типы документов**: PDF, DOC, изображения, чертежи
- **Акты КС-2/КС-3**: Создание, подписание, архив
- **Версионирование**: История изменений документов
- **Права доступа**: Ролевые ограничения

### 7. Система уведомлений
- **Типы**: Информационные, предупреждения, требующие действий
- **Каналы**: В приложении, Email (планируется), SMS (планируется)
- **Триггеры**: Создание смет, платежи, новые задачи
- **Ролевая фильтрация**: По ролям и ответственным

## Безопасность

### Аутентификация
- **Метод**: JWT токены + Refresh Tokens
- **Сессии**: Время жизни токенов
- **Защита**: HTTPS, CORS, Rate Limiting

### Авторизация
- **Модель**: RBAC (Role-Based Access Control)
- **Роли**: Директор, Администратор, Руководитель проекта, Прораб, Сметчик, Снабженец, Клиент
- **Права**: CRUD операции по модулям
- **Проекты**: Изоляция данных по проектам

### Данные
- **Шифрование**: В транзите (TLS) и в покое (опционально)
- **Резервное копирование**: Автоматические бэкапы БД
- **Аудит**: Логирование всех операций

## Масштабируемость

### Горизонтальное масштабирование
- **Load Balancer**: Nginx для распределения нагрузки
- **API Instances**: Множественные инстансы Go API
- **Database**: Read replicas для отчетности
- **Cache**: Redis cluster для кэширования

### Вертикальное масштабирование
- **Оптимизация БД**: Индексы, партиционирование
- **Кэширование**: Многоуровневое кэширование
- **CDN**: Для статических файлов и изображений

## Производительность

### Целевые метрики
- **Время ответа API**: < 200ms для 95% запросов
- **Время загрузки страниц**: < 3 секунды
- **Пропускная способность**: 1000+ одновременных пользователей
- **Доступность**: 99.9% uptime

### Оптимизации
- **Database**: Оптимизированные запросы, индексы
- **Cache**: Кэширование частых запросов
- **API**: Пагинация, фильтрация, сортировка
- **Файлы**: Сжатие, CDN для статики

## Развертывание

### Инфраструктура
- **Контейнеры**: Docker для всех сервисов
- **Оркестрация**: Docker Compose (для начала), Kubernetes (будущее)
- **Мониторинг**: Логирование, метрики, алерты
