# План разработки системы "Строй-Контроль"

## Обзор плана

Данный документ содержит детальный план разработки полнофункциональной системы управления строительными проектами "Строй-Контроль" с интеграцией искусственного интеллекта.

### Текущее состояние
- ✅ **Фронтенд**: Полностью готов (React 19 + TypeScript + Vite)
- ❌ **Бэкенд**: Требует разработки с нуля
- ❌ **База данных**: Не настроена
- ❌ **Интеграция**: Отсутствует

## Технические детали

### Структура проекта бэкенда
```
backend/
├── cmd/
│   └── server/
│       └── main.go
├── internal/
│   ├── config/
│   ├── models/
│   ├── handlers/
│   ├── middleware/
│   ├── services/
│   ├── repository/
│   └── utils/
├── migrations/
├── docker/
├── docs/
└── tests/
```

### База данных - основные таблицы
```sql
-- Пользователи и роли
users, roles, user_roles

-- Проекты
projects, project_team, project_members

-- Сметы
estimates, estimate_items, estimate_versions

-- Финансы
transactions, accounts, finance_articles

-- CRM
leads, counterparties, contact_persons

-- Документы
documents, document_versions, acts

-- Система
notifications, system_logs, audit_trail
```

### API эндпоинты - приоритеты
**Высокий приоритет (Фаза 1)**:
- `/api/v1/auth/*` - Аутентификация
- `/api/v1/users/*` - Пользователи
- `/api/v1/projects/*` - Проекты
- `/api/v1/estimates/*` - Основные CRUD смет

**Средний приоритет (Фаза 2)**:
- `/api/v1/finance/*` - Финансы
- `/api/v1/crm/*` - CRM
- `/api/v1/documents/*` - Документооборот
- `/api/v1/notifications/*` - Уведомления

**Низкий приоритет (Фаза 3)**:
- `/api/v1/ai/*` - AI сервисы
- `/api/v1/reports/*` - Расширенные отчеты
- `/api/v1/admin/*` - Административные функции

## Инструменты разработки

### Локальная разработка
```bash
# Backend
go mod tidy
go run cmd/server/main.go

# Frontend (уже готово)
npm run dev

# База данных
docker-compose up postgres redis
```

### Среда разработки
- **IDE**: VS Code с Go расширениями
- **API тестирование**: Postman/Insomnia
- **База данных**: pgAdmin/DBeaver
- **Логирование**: ELK Stack или простые логи
- **Мониторинг**: Prometheus + Grafana
