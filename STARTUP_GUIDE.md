# Инструкция по запуску приложения Строй-Контроль

## Предварительные требования

- Node.js версии 18 или выше
- npm или pnpm (рекомендуется pnpm)
- API ключ Google Gemini (для работы AI функций)

## Шаг 1: Установка зависимостей

```bash
npm install
# или
pnpm install
```

## Шаг 2: Настройка переменных окружения

Создайте файл `.env.local` в корне проекта со следующим содержимым:

```env
# AI Service Configuration
# Получите API ключ на https://aistudio.google.com/app/apikey
GEMINI_API_KEY=your_api_key_here
```

**Важно**: Замените `your_api_key_here` на ваш реальный API ключ от Google Gemini.

## Шаг 3: Запуск приложения

### Режим разработки

```bash
npm run dev
# или
pnpm dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для production

```bash
npm run build
# или
pnpm build
```

Собранные файлы будут находиться в папке `dist/`

### Предпросмотр production сборки

```bash
npm run preview
# или
pnpm preview
```

## Структура проекта

```
строй-контроль/
├── src/                    # Исходный код приложения
│   ├── components/         # React компоненты
│   ├── pages/              # Страницы приложения
│   ├── services/           # Сервисы (AI, API и т.д.)
│   ├── types.ts            # TypeScript типы
│   └── App.tsx             # Главный компонент
├── index.html              # HTML шаблон
├── vite.config.ts          # Конфигурация Vite
├── tsconfig.json           # Конфигурация TypeScript

```

## Основные функции

- **Управление проектами**: Создание и отслеживание строительных проектов
- **Сметы**: Составление и анализ строительных смет
- **Финансы**: Управление платежами и финансовой отчетностью
- **AI Ассистент**: Интеллектуальный помощник для анализа и рекомендаций
- **CRM**: Управление клиентами и лидами
- **Настройки**: Конфигурация AI провайдеров и моделей

## Решение проблем

### Ошибка "Не указан API ключ"

Убедитесь, что файл `.env.local` создан и содержит корректный `GEMINI_API_KEY`.

### Порт 3000 занят

Измените порт в `vite.config.ts`:

```typescript
server: {
  port: 3001, // или другой свободный порт
  host: '0.0.0.0',
}
```

### Ошибки сборки

1. Удалите `node_modules` и `package-lock.json` (или `pnpm-lock.yaml`)
2. Выполните `npm install` (или `pnpm install`) заново
3. Запустите сборку снова

## Дополнительная информация

- Все AI функции требуют валидный API ключ Google Gemini
- Приложение использует mock данные для демонстрации функциональности
- Для production использования необходимо настроить backend API
