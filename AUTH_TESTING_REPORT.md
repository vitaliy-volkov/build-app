## Тестовые сценарии

### Регистрация
```bash
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email":"test@example.com",
    "name":"Test User",
    "password":"TestPass123",
    "role":"director"
  }'
```

**Ожидаемый результат:**
- Статус: 201 Created
- Response содержит: `{success: true, data: {user: {...}, tokens: {access_token, refresh_token}}}`
- Токены сохраняются в localStorage
- Пользователь автоматически логинится

### Логин
```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email":"test@example.com",
    "password":"TestPass123"
  }'
```

**Ожидаемый результат:**
- Статус: 200 OK
- Response содержит токены
- Токены сохраняются в localStorage
- Пользователь перенаправляется на главную

### Негативные сценарии
1. **Регистрация с существующим email** → 409 Conflict
2. **Логин с неверным паролем** → 401 Unauthorized
3. **Слабый пароль** → 400 Bad Request (валидация на фронте и беке)
4. **Пустые поля** → 400 Bad Request
